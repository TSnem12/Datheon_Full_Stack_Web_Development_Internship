# Developer Portfolio

A responsive developer portfolio showcasing my backend projects, skills, education, and contact links.

🔗 **Live site:** https://tsnem12.github.io/portfolio/

## Features

- Mobile-first responsive layout using Flexbox and CSS Grid
- Dark / light theme toggle, saved in `localStorage`
- Smooth-scrolling navigation and a hamburger menu on mobile
- Project modal popups with details, tech stack and GitHub links
- Semantic HTML5 structure (header, nav, main, sections, footer)
- Downloadable CV

## Sections

About · Skills · Projects · Education · Services · Contact

## Tech Stack

HTML5, CSS3 (custom properties, Flexbox, Grid, media queries), JavaScript (ES6+), GitHub Pages.

## Run Locally

1. Download or clone the repository.
2. Open `index.html` in your browser.

No installation or build step is needed.
